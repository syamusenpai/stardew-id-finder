# Stardew ID Finder

A one-page tool for Stardew Valley 1.6 that builds name-glitch codes.

- Search every item (objects, big craftables, tools, weapons, furniture, clothing, hats, trinkets, flooring, wallpaper) by name or ID.
- Add items to a basket and set the quantity and quality.
- One-click codes for every Community Center bundle, for each whole room, or for all of them at once. One click copies the code.
- Lines are split by on-screen width so the code fits Marnie's text box.

## How to use

1. Back up your save.
2. Open `index.html` in a browser (or the GitHub Pages site).
3. Click a bundle, or search for items and add them to the basket, then copy the code.
4. Buy an animal at Marnie's ranch and paste the code as its name. The items arrive when Marnie's dialogue shows the name.

Quantity, quality and gold only work in **Animal name** mode. The bundle presets use the standard bundles, not Remixed.
